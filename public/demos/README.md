# Демо

## Прототип входа и ролей

Откройте в браузере: **`/demos/auth-flow.html`**

Кликабельный флоу: выбор роли → вход → создание PIN (первый раз) → «Кто пользуется?» → детский / родительский режим (PIN). Сброс PIN: `?reset=1` в URL.

# Демо-видео упражнений

Положите сюда короткие видео (5–15 секунд), показывающие как делать упражнение.

## Имена файлов

| Файл | Упражнение |
|------|------------|
| `arms_up.mp4` | Руки вверх |
| `side_bend.mp4` | Наклон в стороны |
| `squat.mp4` | Присед |
| `one_leg_balance.mp4` | Баланс на одной ноге |
| `goat.mp4` | Жест «коза» |
| `ring.mp4` | Жест «кольцо» |
| `palm_fist.mp4` | Ладонь-кулак |
| `catch_shape.mp4` | Поймай фигуру |

## Рекомендации

- Формат: **MP4** (H.264)
- Длина: **5–15 секунд**, зацикленное
- Без звука (озвучка идёт через приложение)
- Снимайте на телефон: ребёнок или взрослый показывает упражнение крупным планом

Если видео нет — приложение показывает анимированную демонстрацию автоматически.
